# Онлайн-топ Glow Blocks

Для общего топа подключена Firebase Realtime Database проекта `glowblocks-c2e34`:

```text
https://glowblocks-c2e34-default-rtdb.europe-west1.firebasedatabase.app
```

Адрес хранится в `ONLINE_LEADERBOARD_URL` файла `script.js` и будет общим для всех игроков после публикации обновлённых файлов сайта. Адрес из настроек разработчика сохраняется только локально в текущем браузере.

Если в окне топов появится ошибка подключения, проверь правила доступа Realtime Database: они должны разрешать приложению чтение и добавление рекордов. Тестовые правила открывают базу на чтение и запись для всех, поэтому не оставляй их включёнными надолго.
